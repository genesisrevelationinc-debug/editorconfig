## New Properties Proposal

This repository tracks proposals for new EditorConfig properties. One such proposal is the addition of exclude patterns for file listing and search indexing.

### Proposed Properties

| Property | Description |
|----------|-------------|
| `file_exclude_patterns` | Comma-separated list of file globs that should be excluded from file listings (e.g., folder tree panes). |
| `folder_exclude_patterns` | Comma-separated list of folder globs that should be excluded from file listings. |
| `index_exclude_patterns` | Comma-separated list of file/folder globs that should be excluded from search indexing. |
